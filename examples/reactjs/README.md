# React.js Example for DOCX Engine

This is a Vite + React example showing how to use `buatdoc` completely in the browser without a backend.

## Setup

1. Open this `examples/reactjs` directory in your terminal.
2. Install dependencies:
   ```bash
   npm install
   ```

## Running the App

```bash
npm run dev
```
Open the browser at `http://localhost:5173`. You will see a UI to download, preview as Blob, convert to base64, and upload your own `.docx` template!

**Note:** ensure that a `./public/templates/invoice.docx` file exists if you want to test the default template URL generation feature.
